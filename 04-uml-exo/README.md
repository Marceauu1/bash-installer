# Exercise 4 - UML Modeling Practice

## Overview
UML modeling exercises covering class diagrams, sequence diagrams, use case diagrams, inheritance/polymorphism, multiplicities, and design trade-offs.

- **Exo 1 - Hospital Management System:** Patient, Doctor, Organizer (admin), HealthProblem, Prescription, Payment (Check, Cash, CreditCard), User superclass, consultation/registration/payment sequence flows, and architectural reflection questions.
- **Exo 2 - ABCD Records:** Member (Royal, Regular), Non-Member, OrderProcessingClerk, CollectionDepartmentClerk, Order, OrderLine, Item (CD, Tape), Invoice, ShippingList, Payment (Cash, Check, BankDraft), MembershipApplication, use case relationships (`<<include>>`, `<<extend>>`), and sequence flows.

## Workflow
Sketch diagrams on paper first to practice modeling, then record your finalized notes and diagrams in `uml_solutions.md`.
