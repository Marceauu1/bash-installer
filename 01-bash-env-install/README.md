# Exercise 1 — Bash: Configure a Development Environment

## Overview
Automated environment setup script (`env_install.sh`) covering:
- Pretty printing helper (`printf`)
- OS detection via `$OSTYPE`
- Python 3 and `pip` verification/installation
- Jupyter Notebook check/installation
- Homebrew health check (`brew doctor`) on macOS

## Usage
Run `chmod +x env_install.sh` and then `./env_install.sh`.
