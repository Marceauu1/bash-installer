# Exercise 5 - Design Patterns in Practice

## Overview
Refactoring legacy code across three design pattern families:
- **creational/**: Factory Method (Payment system), Builder (HR employee onboarding), Singleton (Configuration manager).
- **structural/**: Adapter (Legacy XML report to JSON dashboard), Decorator (Order pricing system)[cite: 3].
- **behavioral/**: Strategy (Report generator with dynamic format switching + HTML extension), Template Method (Data ETL pipeline + XML pipeline extension).

## Workflow
Sketch UML class diagrams on paper before coding, then implement and test each starter file.
